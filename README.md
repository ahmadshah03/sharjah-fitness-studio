# Sharjah Fitness Studio — Website

A five-page responsive website built for the
CS404 Web Programming and Development unit.
EduQual Level 5 Diploma in Computer Science.

## What It Does

A front-end website for a fictional fitness
studio in Sharjah UAE. Visitors can:
- Browse and filter the class schedule
- Read trainer profiles
- View and compare membership pricing
- Submit a contact or membership enquiry

## Technologies Used

- HTML5 (semantic elements throughout)
- CSS3 (custom properties, Flexbox, Grid,
  media queries, mobile-first design)
- Vanilla JavaScript (DOM manipulation,
  event handling, form validation,
  class schedule filtering)
- Google Fonts (Montserrat, Open Sans)

## How to Run

1. Clone the repository:
   git clone https://github.com/yourusername/
   sharjah-fitness-studio.git
2. Open index.html in any modern browser
3. No build step or dependencies required

## Pages

- index.html — Home, stats, featured classes
- classes.html — Filterable class schedule
- trainers.html — Trainer profiles
- membership.html — Pricing and enquiry form
- contact.html — Contact form and hours

## Accessibility

- WCAG 2.1 Level AA compliant
- Zero errors on WAVE accessibility audit
- Skip navigation link on every page
- All form inputs have explicit label elements
- Hamburger menu uses aria-expanded
- Colour contrast ratio exceeds 4.5:1
